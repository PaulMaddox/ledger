Signed checkpoints

Each checkpoint commits to every entry before it. Signatures are checked here in your browser with the ledger's public key, not taken on trust.

Independent audit

Replays every entry from a snapshot of the journal files and re-checks every hash, signature and balance rule, as a regulator's own tooling would.

Prove history was never rewritten

A consistency proof shows the older checkpoint is an exact prefix of the newer one.

Prove one entry

An inclusion proof shows an entry is in a signed checkpoint, using about log₂(n) hashes.
